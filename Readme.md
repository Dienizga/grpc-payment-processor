# Payment Outbox Processor with gRPC

## 📋 Описание проекта

**Payment Outbox Processor** — это демонстрационный микросервисный проект, реализующий паттерн **Transactional Outbox** для гарантированной доставки событий между сервисами. Проект показывает, как можно надежно передавать данные между микросервисами с использованием **gRPC**, избегая потери сообщений при сбоях.

### Бизнес-сценарий

Клиент отправляет запрос на создание платежа. Система должна:
1. Сохранить платеж в базу данных
2. Отправить уведомление клиенту о начале обработки
3. Гарантировать, что уведомление будет отправлено **даже если сервис уведомлений временно недоступен**

## 🏗 Архитектура

### Микросервисы

#### 1. **payment-service** (порт 8080)
- REST API для создания платежей
- Реализация паттерна Outbox
- gRPC клиент для вызова notification-service
- PostgreSQL для хранения данных

#### 2. **notification-service** (порт 8081)
- gRPC сервер для приема уведомлений
- Эмуляция отправки SMS/Email уведомлений

#### 3. **proto** (общий модуль)
- .proto файлы с описанием контрактов
- Сгенерированные gRPC классы

### Паттерн Transactional Outbox
